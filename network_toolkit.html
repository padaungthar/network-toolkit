Feature Map

  • Subnet Calculator — full port of IP Subnetting.py: network / broadcast / usable range / mask & wildcard / IP class / scope detection, plus IPv6 (compressed & expanded forms, address type, /64 capacity).
  • Ping Sweep — port of ping_script_with range of IP address.py: iterate a start–end range, mark devices online/offline, measure response time, optional reverse-DNS (PTR) lookup per host, CSV export for reports.

Browser Limitations (important)

  • Browsers cannot send ICMP echo. The sweep probes TCP port 80 (configurable) via HTTP — a host that blocks that port will show offline even if it answers ping. Use the Python scripts for ICMP-accurate results.
  • OS / MAC / manufacturer detection requires nmap — run ping_script_with range of IP address.py locally for that (needs sudo for OS fingerprinting).
  • PTR lookups use public DNS-over-HTTPS (Cloudflare) and need internet access.
  • Best used from file:// or an http:// page. If hosted on HTTPS, browsers block probes to plain-HTTP LAN hosts (mixed content).
